# TicketCheck · Proyecto académico

Prototipo web para explorar experiencias y eventos, comparar localidades, seleccionar sillas y simular un proceso de compra.

## Sitio web con GitHub Pages

Este repositorio se puede publicar gratis con GitHub Pages, sin servidor ni compilación.

1. Crea un repositorio **público** en GitHub, por ejemplo `ticketcheck`.
2. Sube `index.html`, `README.md` y `.nojekyll` a la raíz del repositorio (`main`).
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. En **Branch**, selecciona `main`, carpeta `/(root)` y pulsa **Save**.
6. La dirección esperada será `https://TU-USUARIO.github.io/ticketcheck/` (cambia el nombre si el repositorio tiene otro).

Para actualizar el sitio, reemplaza `index.html` en la rama `main` y confirma el cambio. GitHub Pages publicará la nueva versión automáticamente.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Requisitos

- Navegador moderno con conexión a internet.
- Se usan recursos remotos de Google Fonts, Pexels, Google Maps, Tailwind CSS CDN y Lucide. Algunas imágenes, fuentes o mapas podrían no cargar si esos servicios no están disponibles.

## Alcance de la demostración

- Los eventos, fechas, precios, localidades y disponibilidades son ejemplos de carácter académico.
- No se procesan pagos, no se reservan entradas ni se confirma disponibilidad real.
- Favoritos, reseñas, configuraciones y cotizaciones dependen del almacenamiento del navegador y **no se comparten** entre usuarios ni se recopilan en una base de datos.
- No introduzcas datos bancarios ni información personal real en formularios de prueba.

## Tecnología

HTML, CSS y JavaScript, sin backend ni proceso de compilación.
